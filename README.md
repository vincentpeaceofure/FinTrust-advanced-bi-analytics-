## 📊 Executive Summary & Key Insights

1. **Mobile Channel Dominance:** Mobile App serves as the primary driver with over **5.1K transactions**, significantly leading POS (2.4K), Web (1.5K), ATM (1.7K), and USSD (0.5K).
2. **Risk Flag Baseline:** Cross-system validation confirms an overall transaction risk review flag rate of **19.60%** across 12,000 total transactions.
3. **Customer Segment Distribution:** Flagged review transactions are uniformly distributed across customer account tiers (~25% each for Premium, SME, Student, and Everyday).
4. **Volume & Liquidity:** FinTrust processed **₦560.48M** in total transaction volume with an average value of **₦46.71K** per transaction.
